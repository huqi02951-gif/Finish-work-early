# 第一阶段 · 给 GPT 创意导演的素材交接

状态：镜头工程联调版。未通过最终美术验收。目标仍是第一人称机舱 → 手动开门 → 连续坠落 → 入水 → 小海螺感知视角。本轮不改变深海章节。

## 已检出的原素材问题

- `cabin.webp`（1600×900）与 `hatch.webp`（980×1280）为平面插画风，刮痕重复、五金与表面缺少实物质感。现阶段只沿用作工程底图。
- `pov-hands.webp` 仅 388×350，内容混有脚/身体及不完整裁切，不适合作为扶门或双臂特写。保留原文件，但关闭默认显示。
- `seabed.webp` 可以继续作为远景背景，已放入包围视野的曲面；不是三维珊瑚资产。
- 云、波面、折射、泡沫、气泡为工程着色器效果，未采用任何原参考站图片、模型或字体。

## 接入与验收

`src/first-stage/assetManifest.js` 是替换入口。`handsBrace` 与 `handsFreefall` 默认 null，收到批准的组合透明图后填写相对 URL；`HumanForeground.js` 已实现随摄像机的尺度、释放和入水前收手。左右独立手素材需要在同一模块拆成两层并做绑定。`shellRim` 是预留槽，收到成品后再接入，不把当前着色器细弧冒充定装设计。

使用 `http://127.0.0.1:4180/?qa=1` 的机舱/开门/跃出/自由落体/近海/穿水/水下/抵达按钮对齐。检查 1440×900、390×844、320×568 和横屏。每张图保留同构图、光向与尺度；首轮先批准静态机舱与手，再制作动作变体。

参考只用于镜头与空间关系：[Anna Cheng Freefall](https://annacheng8.vercel.app/CARD/)。未经许可不得抽取或复用其专有资产。
