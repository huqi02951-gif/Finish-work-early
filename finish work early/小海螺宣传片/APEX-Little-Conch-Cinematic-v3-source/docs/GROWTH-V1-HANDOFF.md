# 生长与下潜交接 · V3.2 · 2026-10-11

用户最新指令授权艺术化文案、向下输入推进技能、海洋生物贴图、持续生长的片尾及 GitHub/Cloudflare 发布。目录目前仍只有第一阶段 V1 审查稿与 G0 概念板，没有新增正式深海资产。

## 修改

`src/StoryChapters.js` 集中叙事文案，保持外部查询 → 受益所有人 → 财报转换 → 股权穿透 → 技能协作 → 行内部署顺序、既有全息示例和业务含义。

`DiveNavigation.js` 控制连续真实深度 18–320 m 与逐项输入边界；`FirstPersonCamera.js` 的真实高度与 HUD 一致。滚轮向下和手指/鼠标向下拖动推进，反向输入回看，单次输入最多越过一个技能。用户第二轮反馈“过快”后，滚轮每完整进度需 9000 像素、滑动需 6 个屏高，跟随速率 1.15；新技能保留 5 秒阅读窗口，期间忽略正向惯性。邻近下一技能时磁吸到完整阅读点，避免停在空白过渡。01–06 导航支持主动选看。

`SeaLifeEncounters.js` 使用原创透明 atlas，在各深度层呈现小丑鱼、水母、海龟、海马、珊瑚与海星。它们是世界空间 billboard，有视差，但不是骨骼动画 GLB。根据用户第二轮意见改为每项技能一只大图标：桌面左右交替并排介绍，手机大图在上、技能文字在下。旧全息面板与业务示例仍在源码，展示层隐藏，避免与主体争抢视觉。生物沿下潜方向游动，阅读区保持其完整轮廓。

`src/film.js`、`src/first-stage.css`、`index.html` 调整艺术化表达、响应布局和 QA 采样。片尾保留「小海螺诞生于 · 创建团队 / APEX STUDIO」「动画、3D 与网站制作：胡晓丹」，增加「从一个问题，长出万千可能」「下一次好奇，会把我们带向更远的地方」。
