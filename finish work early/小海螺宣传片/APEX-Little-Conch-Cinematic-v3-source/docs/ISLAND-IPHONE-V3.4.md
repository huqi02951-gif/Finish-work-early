# V3.4 · 可见小海螺岛与四项真实授信任务

日期：2026-10-14。沿用现有 V3 工程、镜头和自动部署；完整备份见 `backups/island-iphone-2026-10-14/before.zip`。本轮业务范围已按负责人最新说明校正，见 `LITTLE-CONCH-BUSINESS-TRUTH.md`。

## 当前行为与本轮修改

此前“第一座岛”只有文字，没有可见地形；海底背景与相机同步下移，使深度数字改变而垂直视差不足。已先运行深度视差回归测试并复现失败，再修改背景随动比例，恢复远景相对于视点的位移。

- `ConchIsland.js` 新增真实地形、山脊、海湾、沙滩、棕榈与岩石，作为小海螺岛入口。桌面图文分区，手机上岛下文。镜头与既有坠落路径不碰撞。片尾和顶栏可返回岛屿；进入岛屿后仍是手动开门、自动连续坠落入海，保留故事路线。
- `FirstStageDirector.js` 接入岛屿概览视角、光照与阴影范围，过滤概览中遮住岛屿的近景云。旅程的 `FirstPersonCamera` 和原有坠落轨迹保留。
- `UnderwaterPOV.js` 的远景只跟随68%深度距离。相机实际下潜、远景有视差、色彩随深度吸收暖光，避免只改仪表。原摄影远景作为占位保留。
- `OceanSurface.js` 浅海颜色与岸线泡沫匹配地形；`WaterTransition.js` 调整折射水幕的穿镜时间、遮蔽与深层吸收。仍需正式水面法线与泡沫资产；近镜水纹尚未达到美术验收标准。
- `StoryChapters.js` 保留四项已确认业务：外部风险查询、财报转换、企业股权分析、受益所有人识别。每项配“交给小海螺 / 执行 / 交付”，研发方向明确标注“正在研究”。移除将技能协作与行内部署混排为独立现有能力的六项编号。署名仍为APEX STUDIO、胡晓丹。
- `film.js`、`SeaLifeEncounters.js`、`index.html`、`first-stage.css` 从同一业务数据生成四项导航、标题、海洋生物与片尾索引；大图依次为小丑鱼、海龟、海马、水母。调整小屏文字、标签不换行、短手势提示“上滑下潜 · 下滑回看”；阅读期间正文保持可见。
- `scripts/export-copy.py` 与 `docs/copy/` 导出221项文案及位置映射，新增实际执行/交付字段。旧编号迁移明确标注，后续改稿使用本版CSV。

原生滚动控制器继续作为唯一进度来源，14个初始视口高度；四业务场景各约2.7个视口，浏览器负责惯性，触摸不参与鼠标环顾。没有增加手势拦截或阅读锁。
