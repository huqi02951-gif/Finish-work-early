## 本轮范围与假设

- 初始真实世界高度约 248m（电影坐标），HUD 同单位米；原版 13,500FT 是与画面脱节的叙事刻度。本轮没有将 19 秒镜头声称为物理安全跳水模拟。
- 19 秒镜头中，2.35s 门完全释放、2.8s 开始下落、10.8s 经过 Y=0 海面、19s 抵达约 18m 深处。
- 已确定的外部查询 → 受益所有人 → 财报转换 → 股权穿透 → 技能协同 → 数字员工 → 片尾顺序和文案未重写。只移除外部海螺角色的常驻显示，符合第一人称要求。
- 缺少获批的写实机舱/手部美术，因此这是可验收镜头和交互的工程版本，不是最终画质交付。

## 连续性与性能约束

自由落体采用带终端速度的解析位移：`v²/g × log(cosh(g×t/v))`，海面之后使用初速度连续的指数阻力。HUD 读取同一个导数，不另造速度。纵向位置及一阶速度在入水处连续；姿态由五次平滑曲线采样，暂停和定位不会串行启动旧 tween。

GSAP 仅用于未提交的手动开门回弹；自动镜头由绝对时钟驱动。后台冻结、每帧推进上限 50ms，避免失焦回来跨过入水。弱设备可能延长墙钟播放时间，优先保留镜头。

DPR 桌面上限 1.5、窄屏上限 1.35；180 个有效帧平均超过 29ms 时降到 1。云层/水下粒子窄屏减量。没有逐帧创建 GSAP tween 或重复加载图片。帧间隔指标是浏览器 RAF 采样，不是 GPU profiler，也不能代表真实手机性能。

材质与远景画质局限见 `ASSET-REQUESTS.md`。运动模糊为屏幕径向多采样，不是逐物体运动向量或离线渲染。
